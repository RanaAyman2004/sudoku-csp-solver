# 🧩 Sudoku CSP Solver

A Python-based Sudoku solver that uses Constraint Satisfaction Problem (CSP) techniques, including Backtracking and Arc Consistency (AC-3). Built as a team project for our AI course.

## ✨ Features
*   **3 Solving Modes:** Backtracking (MRV), AC-3, and combined AC-3→BT.
*   **Interactive Modes:** Auto-solve, user input, and playable mode with conflict checking.
*   **Visual Feedback:** Animated solving process with pygame.

## 🛠️ Technologies
*   Python 3
*   Pygame
